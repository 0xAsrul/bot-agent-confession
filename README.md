## What it does

`main.py` writes one funny single-line secret confession — something an AI
agent did and does not want its user to know — to `/output/entry.txt`.

The confession is under 200 characters, a single line, deterministic, with
no randomness and no network access.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
